Detailed Description

template<typename T>
class estimators::mvue::MVUE_4< T >

Minimum Variance Unbiased Estimator for four measurements.

The MVUE_4 class combines four measurements into a single estimate while minimizing the variance of the resulting estimate under the assumptions of the estimator.

Each measurement is associated with a variance. Measurements with lower variance receive greater weighting in the resulting estimate.

Template Parameters
TNumeric data type used for the estimator.
Example
estimators::mvue::MVUE_4<double> estimator;
estimator.init(var1, var2, var3, var4);
double estimate = estimator.update(x1, x2, x3, x4);
