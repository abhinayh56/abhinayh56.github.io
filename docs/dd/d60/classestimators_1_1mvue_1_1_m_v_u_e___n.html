Detailed Description

template<typename T, std::size_t N>
class estimators::mvue::MVUE_N< T, N >

Minimum Variance Unbiased Estimator for N measurements.

The MVUE_N class combines N measurements into a single estimate while minimizing the variance of the resulting estimate under the assumptions of the estimator.

Each measurement has an associated variance. Measurements with lower variance receive greater weighting in the resulting estimate.

The number of measurements is specified at compile time through the N template parameter.

Template Parameters
TNumeric data type used for the estimator.
NNumber of measurements.
Example
constexpr std::size_t N = 5;
estimators::mvue::MVUE_N<double, N> estimator;
double variances[N] = {
var1, var2, var3, var4, var5
};
estimator.init(variances);
double measurements[N] = {
x1, x2, x3, x4, x5
};
double estimate = estimator.update(measurements);
