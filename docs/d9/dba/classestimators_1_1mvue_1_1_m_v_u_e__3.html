Detailed Description

template<typename T>
class estimators::mvue::MVUE_3< T >

Minimum Variance Unbiased Estimator for three measurements.

The MVUE_3 class combines three measurements into a single estimate while minimizing the variance of the resulting estimate under the assumptions of the estimator.

Each measurement is associated with a variance. Measurements with lower variance receive greater weighting in the resulting estimate.

Template Parameters
TNumeric data type used for the estimator.
Example
estimators::mvue::MVUE_3<double> estimator;
estimator.init(var1, var2, var3);
double estimate = estimator.update(x1, x2, x3);
